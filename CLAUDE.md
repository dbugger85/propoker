# ProPoker

A poker tournament manager for the organiser's own phone or tablet: a blind clock with sounds, players and knockouts, rebuys and add-ons, several tables with seat draw and balancing, the chip set, the prize pool and payouts, and an end-of-night summary for the group chat. A sister app to Substitutor (`~/Work/substitutor`): same stack, same glass look. `PLAN.md` has the plan; section 9 is the dated log of every decision the owner made (add new ones there, newest last). Section 10 (chip counts and the drawn table view) is built.

The owner is a beginner: explain in plain words. Commit and push only when asked, and never put the claude.ai session link in commits.

## Commands
- `npm start` – serves the app at http://localhost:8000
- `npm test` – unit tests for the logic (node --test), including "every text is translated"
- `npm run e2e` – Playwright plays a whole tournament on a phone (12 players, 2 tables, drawn tables and seat swaps, a chip count at a break, rebuy, knockouts, balancing, final table, summary, a deal) plus a tablet sideways and Norwegian. Needs `/usr/bin/chromium`. Screenshots in `test/screenshots/` (gitignored); look at them after UI changes.
- `npm run screenshots` – the README pictures (`screenshots/`, including the main menu with two made-up filed-away evenings), the start page's tour (`screenshots/tour/*-light.webp` and `*-dark.webp`, via `magick`) and `icons/preview.png`, from a made-up Friday evening (14 players, level 6, the time pinned to 21:12). Run it when the look changes.

Run `npm test` and `npm run e2e` after any change.

## Deploy
Public repo `dbugger85/propoker`, GitHub Pages from `main` / root, live at https://dbugger85.github.io/propoker/ (canonical and Open Graph tags in `index.html` point there; change them if a domain like propoker.no is bought). `git push` redeploys in about a minute.

## Rules
- The start page promises "100% free · No ads · No tracking · No account · Works offline" (`.promise`, like PrimeTime): keep it true. No analytics, cookies or ad scripts, ever.
- Plain HTML/CSS/JS, ES modules, no framework, no build step. Only relative paths.
- `js/*.js` other than `app.js` hold no DOM code, so node can test them.
- Never the browser's `alert`/`confirm`/`prompt` or `<select>`: use `ask()` and `pickFrom()` in `app.js` (the e2e test fails on a native popup).
- All colours are CSS variables: light in `:root`, dark repeated under `prefers-color-scheme: dark` and `:root[data-theme="dark"]`; change both. Exception: real chip colours (`CHIP_COLORS` in `chips.js`) and the flags.
- Tap targets ≥ 48px (44 for small secondary ones). Phone first (~390px).
- Short labels must not wrap (owner's wish): pick short words (check both languages at 390 px), and use `white-space: nowrap` with an ellipsis for names and sub-lines.
- Thousands are split by a no-break space (owner's wish): `groupDigits()` for chips, `formatMoney()` for money, always the code first: "NOK 1 000" in every language (both in `money.js`). Never `toLocaleString()`.
- Chips are SVG from `chipSvg()` (owner's wish: vector, no CSS gradient tricks), shown by `chipDot()` in `app.js`. **Own colour…** in the colour list opens the phone's colour picker (`#color-input`).
- Input boxes are recessed wells (`--well`, `--well-line`), not glass; buttons stay glass (owner's wish).
- Number boxes are `type="text"` with `inputmode="numeric"` (or `decimal`), never `type="number"`, so they can show the thousands split; they're right-aligned (owner's wish). A document-level listener in `app.js` splits the thousands as you type; read them with `num()` and fill them with `setNum()` / `boxText()`, never `.value =` directly.
- The English text is the translation key: `tr('Add player')`. Add every new text to `NO` in `js/i18n.js`; `test/i18n.test.js` finds missing ones (tr() calls, `data-t` in the HTML, `[value, 'Label']` lists).
- When you add, rename or remove a file the app loads, update `FILES` in `sw.js`.

## How it works
- **Start page / main menu**: New tournament (a blank one; the open one is filed away first unless it's still empty), **Your tournaments** (`renderHome()`: every tournament, newest first, with its state; tap = `openEntry()` to its setup, game or summary; ⋮ = `entryOptions()`: open, New tournament with this setup (`copySetup()`), Delete), Export everything / Import (one JSON file `{ app: 'ProPoker', v, names, tournaments: [{ id, created, setup, game }] }`, via the share sheet or a download; import replaces same ids), the intro, the promise line, a swipeable tour of six screenshots (`.tour`, WebP in `screenshots/tour/<name>-light|dark.webp`, also cached by `sw.js`; each figure has a `.light-pic` and a `.dark-pic` and CSS shows the one for the theme, owner's wish), install card, GitHub link.
- **Several tournaments** (owner's wish): the open one lives in `propoker.setup` + `propoker.tournament` as before (id and created time in `propoker.current`); the others are filed away whole in `propoker.saved.<id>` (`switchTo()`, `savedTournaments()`, `clearCurrent()` in `storage.js`). Each keeps its own setup, also after it's started. The saved names (`knownNames`) go along to whichever is open. Opening another pauses a running clock (one clock at a time). The house button (`#home-btn`, every screen but home) goes to the main menu; the clock keeps its time and the game opens again from the list. On load, a running game opens straight away; otherwise the main menu.
- **Setup** saves as you type (`propoker.setup`). Order: Tournament, Players (early, owner's wish: the length, chip check and payouts depend on them), Chips, Blinds, Rebuys and add-ons, Tables, Payouts. The saved names (`setup.knownNames`, tap to add) have **Edit** (`knownButtons()`): each gets a ✕, and a tap forgets it. **Reset all settings** (by Share these settings) saves only the players and names, reloads the defaults through `loadSetup()`, with Undo in the toast. A preset button rebuilds the levels (always the default); editing a level, Add level or Add break makes it Custom. Your own levels are also kept in `setup.customLevels` (saved in `saveS()` while on Custom), so tapping **Custom** brings them back after looking at a preset; the first time it starts from the structure you were on. Minutes per level/break apply to all levels. **Tournament length** (`setup.targetHours`, a picker at the top of Blinds): with a preset, `saveS()` rebuilds the levels to fit it whenever anything changes. The smallest chip in the chip set rounds the blinds. The level list shows 8 rows until "Show all". Breaks have a drag handle (`dragBreak()`, pointer events; the dragged row stays in the DOM and its neighbours move) in setup and in the cog (not above the level being played).
- **Chip set**: values are game points, not money (owner's wish: chips need not be 1:1 with the buy-in). Setup shows each stack (start, rebuy, add-on) as chips and, when "You have" is filled in, how many players the chips are enough for. On the clock page a legend shows the chips; ones no longer needed are struck out, and at a break the status line and overlay say "Colour up".
- **The tournament** (`propoker.tournament`, opens straight away on load while it's running). The clock starts paused ("Start the clock"). `tick()` every 500 ms: catch-up, the one-minute beep, a chime and a 5 s overlay at each new level or break. `propoker.seen` is saved every 15 s; opening the app more than 2 min after that with the clock running asks "keep it running, or stop where it was".
- **Phone**: four swipeable pages with labelled dots (Clock, Players, Tables, Money) in a bar at the top that stays while scrolling (sticky), and a small clock strip below it on the other pages. **Tablet sideways** (`body.wide`, ≥ 860×560 landscape): the clock fills the left, the right is a panel with tabs; `.pages` becomes `display: contents` in a grid.
- **Players**: tap a player for Knocked out (rebuy question while rebuys are open, then "who knocked them out", skippable), Rebuy, Add-on, Payment, Change seat, Chip count, Left the game; the pencil by the name renames. No "…" on these buttons (owner's wish). Fixing mistakes later: Take back a rebuy (`T.takeBackRebuy`, back out as before if it brought them in), and for players who are out Change place (`T.setPlace`), Knocked out by (`T.setOutBy`), Not out after all (`T.backIn`). Rebuys/late entry/add-ons after the cut-off ask "allow anyway?". A toast with Undo after each action, and an Undo button.
- **Chip counts**: each player has `stack` (last count, or null) and `stackLevel`; `game.counts` is the history. At a break the clock page shows **Count chips** (also in the cog, and "Chip count" in a player's options for one player). The popup lists players table by table in seat order; empty boxes keep the last count; Enter jumps to the next box; the bottom compares with chips in play (warning only). Rebuys/add-ons after a count add to the stack, a knockout clears it, late/back-in players get a known stack once there's been a count. The chip leader shows as the Players fact's sub-line, a badge on the Players page and a gold ring on the drawn table; the Players page can sort by stack.
- **Tables**: drawn by default (`drawnTable()`: a felt stadium with a `--rail`, seats placed by `seatPositions`, aspect 3:2 to match `TABLE_ASPECT`); the **List** toggle (`propoker.tableView`, per device) shows the old seat grid. Phone: tables stacked; tablet upright (≥ 680 px): two side by side; sideways: stacked in the panel. Pending movers pulse amber with "→ seat". The dealer's spot (top middle, `dealerSpot()`; seats from the dealer's left via `seatPositions(…, dealer)`) is on unless turned off in the cog (`propoker.dealer`, per device). After every change `replan()` works out the moves from where people sit (`game.pending`); the popup opens with them, a banner stays until "They have moved". "Someone else" picks another player from the same table for a balance move. **Manual moves** (owner's wish): tap a player's seat, then any seat at any table; two players swap, an empty seat is a move.
- **Money**: pool, money in (paid so far, of the total), still to pay, paid places, prizes by place, and a Payments list (who owes first; tap for Paid everything / Paid part / Not paid, `openPayment()`). Nobody has paid at the start. Payouts can be changed during the game.
- **Links**: "Share these settings" (setup) and "Continue on another device" (cog) share a link via the share sheet (else copy). On load, `openSharedSettings()` / `openSharedTournament()` read the hash, ask first, then clear it; both make a new tournament in the list (settings links during a running game are only filed away, so the clock isn't stopped); with a link, the "clock kept running" question is skipped.
- **The end**: when one player is left, or the cog's End tournament (with players left: a deal, split evenly by default). The summary has results ("Out by …"), settle-up (who sends what to whom, with a picker for who has the money paid in), won and lost (prize minus bought), facts, Share results (share sheet, else copy), Main menu, Play again (`copySetup()`: same setup and players), and a small Undo the last knockout / Undo the deal link (owner's wish: clearer buttons).
